# Long Note for Scroll Testing

This note exists so you can test long-form reading, scrolling, and outline behavior.

## How to use this page

Open this file from the folder panel and scroll top to bottom.

### What to watch

- Sidebar resize while note is very long
- Outline navigation jump behavior
- Overall readability over long sessions

## Section 1

This is section 1 of the long note. The goal is not special content, just enough realistic text volume to validate spacing, rhythm, and navigation.

### Detail 1.1

When the content grows, the design should stay calm. Headings should remain clear, paragraphs should not feel cramped, and sidebar behavior should remain stable.

### Detail 1.2

A minimal interface works best when interaction feels predictable. That includes smooth scrolling, steady anchors, and no layout jumps while reading.

### Detail 1.3

If this section feels easy to scan, the typography settings are doing their job. If it feels noisy, reduce contrast changes and visual clutter.
